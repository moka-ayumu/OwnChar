# PG-04 미리보기 페이지

- **경로**: `/preview`
- **대응 Use Case**: UC-06, UC-09
- **목적**: 사용자가 생성된 폰트를 확인하고 OTF 파일을 내려받습니다.

## 진입 조건

- PG-03에서 생성이 끝납니다.
- PG-01에서 폰트가 있는 상태로 **이어서 만들기**를 누릅니다.
- PG-02에서 **기존 폰트 미리보기 · 편집**을 누릅니다.
- PG-05에서 **미리보기**를 누릅니다.
- 생성된 폰트가 없으면 시스템이 PG-02를 엽니다.

## 표시 데이터

| 데이터 | 설명 |
|--------|------|
| 제목 | 폰트가 완성되었음을 알립니다 |
| 미리보기 문장 | 사용자의 폰트로 표시합니다 |
| 견본 문장 | 한글 가나다, 영문 대문자, 영문 소문자, 숫자 |
| 폰트 정보 | 폰트 이름, 제작자, 버전 |

## 요소

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 미리보기 입력 | 여러 줄 입력 | 사용자가 입력한 문장을 즉시 사용자의 폰트로 표시합니다. 기본값은 「오늘 하루도 좋은 하루 보내세요.」입니다 | 항상 |
| 글자 크기 | 슬라이더 | 미리보기 글자 크기를 정합니다. 범위는 36 px에서 160 px까지입니다 | 항상 |
| 견본 문장 | 버튼 목록 | 누르면 미리보기 입력을 그 견본으로 바꿉니다 | 항상 |
| 폰트 이름 | 텍스트 입력 | 폰트 이름을 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| 제작자 | 텍스트 입력 | 제작자를 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| 버전 | 텍스트 입력 | 버전을 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| OTF 다운로드 | 버튼 | `폰트이름.otf` 파일을 내려받습니다 | 항상 |
| 변경 안내 | 알림 | 필기 또는 설정이 변경되었음을 알립니다 | 폰트가 「변경됨」일 때 |
| 변경 적용 | 버튼 | PG-03을 엽니다 | 폰트가 「변경됨」일 때 |
| 글자 다시 쓰기 | 버튼 | PG-02를 엽니다 | 항상 |
| 고급 편집 | 버튼 | PG-05를 엽니다 | 항상 |
| 서버 미전송 안내 | 문구 | 폰트를 서버로 전송하지 않는다고 알립니다 | 항상 |

## 상태

| 상태 | 표시 |
|------|------|
| 폰트가 최신임 | 변경 안내 없음 |
| 폰트가 「변경됨」 | 변경 안내와 변경 적용 표시 |
| 폰트를 브라우저에 등록하는 중 | 기본 글꼴로 임시 표시 |
