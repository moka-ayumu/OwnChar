# PG-04 미리보기 페이지

- **경로**: `/preview`
- **대응 Use Case**: UC-06, UC-09
- **목적**: 사용자가 생성된 폰트를 확인하고 OTF 파일을 내려받습니다.

## 진입 조건

- PG-03에서 생성이 끝납니다.
- PG-01에서 폰트가 있는 상태로 **이어서 만들기**를 누릅니다.
- PG-02에서 **기존 폰트 미리보기 · 편집**을 누릅니다.
- PG-05에서 **미리보기**를 누릅니다.
- 생성된 폰트가 없으면 시스템이 PG-02를 엽니다.

## 표시 데이터

| 데이터 | 설명 |
|--------|------|
| 제목 | 폰트가 완성되었음을 알립니다 |
| 미리보기 문장 | 현재 필기와 설정으로 즉시 조합하여 표시합니다 |
| 크기 다이얼 | 글자 폭, 초성 크기, 중성 크기, 종성 크기. 0%는 쓴 그대로이고 100%는 같은 구조의 글자들의 평균입니다. 100%를 넘으면 평균에서 먼 글자까지 맞춥니다. 기본값은 100%입니다 |
| 원본 필기 | 선택한 글자의 자모마다 그 자모를 쓴 칸 |
| 폰트 정보 | 폰트 이름, 제작자, 버전 |

## 요소

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 미리보기 입력 | 여러 줄 입력 | 사용자가 입력한 문장을 즉시 사용자의 폰트로 표시합니다. 기본값은 「오늘 하루도 좋은 하루 보내세요.」입니다 | 항상 |
| 글자 크기 | 슬라이더 | 미리보기 글자 크기를 정합니다. 범위는 36 px에서 160 px까지입니다 | 항상 |
| 글자 고르게 | 슬라이더 | 크기 다이얼 4개를 같은 값으로 정합니다. 범위는 0%에서 200%까지입니다. 다이얼 값이 서로 다르면 평균을 표시합니다 | 항상 |
| 세부 조정 | 펼침 버튼 | 다이얼 4개의 슬라이더를 엽니다. 열림 상태는 기기에 저장합니다 | 항상 |
| 글자 폭, 초성 크기, 중성 크기, 종성 크기 | 슬라이더 | 다이얼 하나를 정합니다. 범위는 0%에서 200%까지입니다 | 세부 조정이 열렸을 때 |
| 기본값으로 | 버튼 | 다이얼 4개를 100%로 되돌립니다 | 다이얼이 100%가 아닐 때 활성 |
| 원본 필기 | 팝오버 | 선택한 글자의 자모마다 쓴 칸의 그림과 문장 이름을 보여 줍니다. 자모를 누르면 PG-02에서 그 칸을 엽니다. 앞의 4글자까지 표시합니다 | 입력 영역에서 글자를 선택했을 때. 페이지를 열면 첫 두 글자가 선택되어 있습니다 |
| 폰트 이름 | 텍스트 입력 | 폰트 이름을 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| 제작자 | 텍스트 입력 | 제작자를 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| 버전 | 텍스트 입력 | 버전을 정합니다. 변경하면 폰트를 「변경됨」으로 표시합니다 | 항상 |
| OTF 다운로드 | 버튼 | `폰트이름.otf` 파일을 내려받습니다 | 항상 |
| 변경 안내 | 알림 | 필기 또는 설정이 변경되었음을 알립니다 | 폰트가 「변경됨」일 때 |
| 변경 적용 | 버튼 | PG-03을 엽니다 | 폰트가 「변경됨」일 때 |
| 글자 다시 쓰기 | 버튼 | PG-02를 엽니다 | 항상 |
| 고급 편집 | 버튼 | PG-05를 엽니다 | 항상 |
| 서버 미전송 안내 | 문구 | 폰트를 서버로 전송하지 않는다고 알립니다 | 항상 |

## 상태

| 상태 | 표시 |
|------|------|
| 폰트가 최신임 | 변경 안내 없음 |
| 폰트가 「변경됨」 | 변경 안내와 변경 적용 표시 |
| 폰트를 브라우저에 등록하는 중 | 기본 글꼴로 임시 표시 |
| 입력한 글자를 조합하는 중 | 생성된 폰트의 글자로 임시 표시 |
| 선택한 자모를 아직 쓰지 않음 | 원본 필기에 "아직 쓰지 않았어요"를 표시. 누를 수 없음 |

변경 안내와 변경 적용은 크기 다이얼 아래에 표시합니다. 그래서 다이얼을 움직일 때 입력 영역이 밀리지 않습니다.
