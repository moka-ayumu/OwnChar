# UC-04 문장을 이동하고 다시 쓴다

- **액터**: 사용자
- **화면**: 쓰기(`/write`)의 좌측 패널

## 기본 흐름: 문장 이동

1. 사용자가 좌측의 "연습 문장" 목록을 봅니다.
2. 각 항목에 번호, 문장 제목, `수집한 개수 / 필요 개수`가 표시됩니다. 완료한 문장에는 번호 대신 ✓가 표시됩니다.
3. 현재 문장은 강조됩니다.
4. 사용자가 **다음 문장** 버튼, **이전 문장** 버튼 또는 목록의 항목을 누릅니다.
5. 시스템이 해당 문장을 마지막으로 저장한 상태로 엽니다. 저장 대상은 획, 경계, 가이드, 칸 크기, 열 수입니다.
6. 시스템이 현재 문장의 번호를 저장합니다.
7. 마지막 문장에서는 **다음 문장** 버튼 대신 **폰트 만들기** 버튼이 표시됩니다. 이 버튼은 UC-05에서 사용합니다.

## 대안 흐름 A: 수집한 자모를 다시 쓰기

1. 사용자가 문장을 지우고 다시 씁니다. 또는 칸에 다른 획을 씁니다.
2. 시스템이 이 문장에서 이전에 수집했고 더 이상 쓰이지 않는 자모를 삭제합니다.
3. 시스템이 새로 쓴 자모로 교체합니다.
4. 다른 문장에서 수집한 자모는 변하지 않습니다.
5. 이미 쓴 칸은 쓸 때의 가이드를 유지합니다.

## 대안 흐름 B: 편집 화면에서 원본 필기로 이동

1. 사용자가 UC-07에서 글리프의 "원본 필기" 링크를 누릅니다.
2. 시스템이 쓰기 화면에서 해당 문장을 엽니다.
3. 시스템이 원본이 된 칸을 강조하고, 그 위치까지 스크롤합니다.
4. 사용자가 그 칸에서 바로 고쳐 쓸 수 있습니다.
5. 사용자가 다른 문장으로 이동하면 강조 표시가 사라집니다.
6. 좌측 하단의 **기존 폰트 미리보기 · 편집** 버튼이 `/edit`를 엽니다. 시스템은 보던 글리프를 선택한 상태로 엽니다.

## 대안 흐름 C: 기존 폰트로 돌아가기

- 생성한 폰트가 있으면 좌측 하단에 **기존 폰트 미리보기 · 편집** 버튼이 항상 표시됩니다.
- 사용자가 이 버튼을 누르면 시스템이 쓰기를 중단하고 `/preview`를 엽니다.

## 사후 조건

- 문장을 이동해도 쓴 내용은 사라지지 않습니다.
- 시스템이 마지막으로 본 문장을 저장합니다. 다음 방문에서 같은 문장이 열립니다.
