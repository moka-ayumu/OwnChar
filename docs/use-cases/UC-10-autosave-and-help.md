# UC-10 자동 저장과 도움말을 사용한다

- **액터**: 사용자
- **화면**: 전체

## 자동 저장

사용자는 저장 버튼을 누르지 않습니다. 시스템이 자동으로 저장합니다.

### 저장 단계

1. 사용자가 획을 쓰거나 지웁니다.
2. 시스템이 250 ms 기다립니다. 그 후 시스템이 문장 세션과 수집한 자모를 프로젝트에 기록합니다.
3. 프로젝트 상태가 바뀌면 시스템이 450 ms 기다립니다.
4. 시스템이 프로젝트 전체를 IndexedDB에 기록합니다.

### 저장되는 내용

- 쓴 획, 자모 경계, 가이드, 칸 크기
- 수집한 자모
- 폰트 이름, 제작자, 버전
- 보정값과 편집 기록
- 조합 설정과 전체 여백
- 생성된 폰트(OTF 데이터)
- 마지막으로 본 문장

자리 안내(점선 상자)의 켬과 끔은 별도로 이 기기의 localStorage에 저장됩니다.

### 복원

1. 사용자가 브라우저를 닫습니다.
2. 사용자가 나중에 OwnChar를 엽니다.
3. 시스템이 IndexedDB에서 프로젝트를 읽습니다.
4. 저장된 형식의 버전이 현재 버전과 다르면 시스템은 그 프로젝트를 열지 않습니다. 시스템이 빈 프로젝트로 시작합니다.
5. 사용자가 홈에서 **이어서 만들기**를 누릅니다. 이 단계는 UC-01입니다.

### 저장할 수 없는 경우

- IndexedDB를 사용할 수 없으면 시스템이 오류를 표시하지 않고 메모리에서 계속 동작합니다.
- 이 경우 새로고침하면 작업이 사라집니다.

## 도움말

1. 사용자가 상단 헤더의 **도움말**을 누릅니다.
2. 시스템이 `/license` 화면을 엽니다.
3. 화면에 다음 내용이 표시됩니다.
   1. 데이터를 브라우저 안에서만 처리한다는 안내
   2. 작성 방법 4단계
   3. 사용한 오픈소스 라이브러리 목록
4. 사용자가 **돌아가기**를 누르면 시스템이 홈을 엽니다.
