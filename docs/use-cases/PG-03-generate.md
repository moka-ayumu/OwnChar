# PG-03 생성 페이지

- **경로**: `/generate`
- **대응 Use Case**: UC-05, UC-09
- **목적**: 시스템이 폰트를 생성하는 동안 진행 상황을 보여 줍니다.

## 진입 조건

- PG-02에서 폰트 생성을 시작합니다.
- PG-04 또는 PG-05에서 **변경 적용**을 누릅니다.

## 동작

1. 페이지를 열면 시스템이 즉시 생성을 시작합니다. 사용자의 추가 조작은 필요하지 않습니다.
2. 생성이 끝나면 시스템이 PG-04를 엽니다.
3. 사용자가 취소하면 시스템이 PG-02를 엽니다.

## 표시 데이터

| 데이터 | 설명 |
|--------|------|
| 제목 | 폰트를 생성하는 중임을 알립니다 |
| 진행 메시지 | 현재 단계를 보여 줍니다. 한글 조합 단계에서는 `N / 11,172`를 포함합니다 |
| 진행률 | 0에서 100까지의 값. 막대와 숫자로 표시합니다 |

## 요소

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 진행 막대 | 표시 | 진행률을 보여 줍니다 | 항상 |
| 진행 메시지 | 표시 | 현재 단계를 보여 줍니다 | 항상 |
| 생성 취소 | 버튼 | 생성을 중지하고 PG-02를 엽니다. 이전 폰트는 유지됩니다 | 오류가 없을 때 |
| 오류 메시지 | 알림 | 오류 내용을 보여 줍니다 | 생성이 실패했을 때 |
| 다시 시도 | 버튼 | 생성을 처음부터 다시 실행합니다 | 생성이 실패했을 때 |

## 상태

| 상태 | 표시 |
|------|------|
| 생성 중 | 진행 막대, 진행 메시지, 생성 취소 |
| 실패 | 오류 메시지, 다시 시도 |
| 완료 | 시스템이 PG-04를 엽니다 |
| 취소 | 시스템이 PG-02를 엽니다 |
