# UC-06 결과를 확인하고 OTF 파일을 내려받는다

- **액터**: 사용자
- **화면**: 미리보기(`/preview`)
- **사전 조건**: 생성된 폰트가 있습니다. 폰트가 없으면 시스템이 쓰기 화면(`/write`)을 엽니다.

## 기본 흐름

1. 사용자가 미리보기를 엽니다.
2. 시스템이 생성된 폰트를 브라우저에 등록합니다.
3. 시스템이 "손글씨가 폰트가 되었어요." 제목을 표시합니다.
4. 입력 영역에 기본 문장 "오늘 하루도 좋은 하루 보내세요."가 사용자의 폰트로 표시됩니다.
5. 사용자가 입력 영역에 원하는 문장을 입력합니다.
6. 시스템이 입력한 글자를 즉시 사용자의 폰트로 표시합니다.
7. 사용자가 **글자 크기** 슬라이더로 크기를 정합니다. 범위는 36 px에서 160 px까지입니다.
8. 사용자가 하단의 견본 문장을 누릅니다. 견본은 한글 가나다, 영문 대문자, 영문 소문자, 숫자입니다.
9. 시스템이 입력 영역의 문장을 그 견본으로 바꿉니다.
10. 사용자가 우측 패널에서 폰트 이름, 제작자, 버전을 입력합니다.
11. 사용자가 **OTF 다운로드**를 누릅니다.
12. 시스템이 `폰트이름.otf` 파일을 내려받습니다. 폰트 이름에서 파일 이름에 쓸 수 없는 문자는 바뀝니다.

## 대안 흐름

### 메타데이터를 변경함

1. 사용자가 폰트 이름, 제작자 또는 버전을 바꿉니다.
2. 시스템이 폰트를 "변경됨"으로 표시합니다.
3. 시스템이 안내 배너를 표시합니다. 배너는 "필기 또는 폰트 생성 설정이 변경되었습니다."로 시작합니다.
4. 새 이름이 들어간 OTF 파일이 필요하면 UC-09를 실행합니다.

### 다른 화면으로 이동

| 버튼 | 이동 |
|------|------|
| 글자 다시 쓰기 | 쓰기(`/write`). UC-02와 UC-04를 사용합니다 |
| 고급 편집 | 편집(`/edit`). UC-07과 UC-08을 사용합니다 |

## 사후 조건

- 사용자의 컴퓨터에 OTF 파일이 저장됩니다.
- 시스템은 서버로 폰트를 전송하지 않습니다. 폰트는 이 브라우저에서 생성됩니다.
