# PG-01 홈 페이지

- **경로**: `/`
- **대응 Use Case**: UC-01
- **목적**: 사용자가 작업을 시작하거나 이어서 합니다.

## 진입 조건

- 사용자가 OwnChar를 처음 엽니다.
- 사용자가 공통 헤더의 로고를 누릅니다.
- 사용자가 PG-07에서 **돌아가기**를 누릅니다.

## 표시 데이터

| 데이터 | 조건 |
|--------|------|
| 제품 설명 문구 | 항상 |
| 만드는 과정의 애니메이션: 문장 쓰기, 간격 학습, 획 다듬기, 자모 수집, 문맥형, 글자 조합, 폰트 완성 | 항상 |
| 현재 장면의 이름과 설명 한 줄 | 항상 |
| 수집 진행률: `수집한 개수 / 필수 개수` | 이어서 만들 수 있을 때 |

## 요소

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 새 폰트 시작하기 | 버튼 | 저장된 작업을 삭제하고 빈 프로젝트를 만듭니다. 그 후 PG-02를 엽니다 | 항상 |
| 이어서 만들기 | 버튼 | 폰트가 있으면 PG-04를, 없으면 PG-02를 엽니다 | 이어서 만들 수 있을 때 |
| 처음부터 다시 만들기 | 링크 버튼 | 「새 폰트 시작하기」와 같은 동작을 실행합니다 | 이어서 만들 수 있을 때 |
| 진행 막대 | 표시 | 수집 진행률을 보여 줍니다 | 이어서 만들 수 있을 때 |
| 예시 손글씨 | 버튼 | 저장된 작업을 삭제하고 예시 손글씨로 프로젝트를 채웁니다. 그 후 PG-02를 엽니다 | 항상 |
| 장면 목록의 행 | 버튼 | 애니메이션을 그 장면부터 재생합니다. 동작 줄이기 설정에서는 그 장면의 정지 화면을 표시합니다 | 항상 |
| 일시정지 / 재생 | 아이콘 버튼 | 애니메이션을 멈추거나 다시 재생합니다 | 동작 줄이기 설정이 꺼져 있을 때 |

**이어서 만들 수 있을 때**의 정의: 수집한 자모가 1개 이상이거나, 생성된 폰트가 있습니다.

## 대화상자

| 이름 | 표시 시점 | 선택 |
|------|-----------|------|
| 새로 시작 확인 | 저장된 작업이 있고 사용자가 새로 시작하려 할 때 | 확인: 작업을 삭제하고 새로 시작합니다. 취소: 아무 변화도 없습니다 |
| 예시 불러오기 확인 | 저장된 작업이 있고 사용자가 예시 손글씨 버튼을 누를 때 | 확인: 작업을 삭제하고 예시 손글씨를 불러옵니다. 취소: 아무 변화도 없습니다 |

## 상태

| 상태 | 표시 |
|------|------|
| 저장된 작업을 읽는 중 | 「작업을 불러오는 중」 |
| 저장된 작업이 없음 | 「새 폰트 시작하기」와 예시 손글씨 버튼을 표시 |
| 예시 손글씨를 불러오는 중 | 버튼에 「불러오는 중…」을 표시. 버튼을 비활성화 |
| 저장소를 사용할 수 없음 | 저장된 작업이 없는 상태와 같음 |
