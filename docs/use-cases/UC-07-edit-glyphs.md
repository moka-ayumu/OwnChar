# UC-07 글리프를 개별로 보정한다

- **액터**: 사용자
- **화면**: 편집(`/edit`)의 "글리프 편집" 모드
- **사전 조건**: 생성된 폰트가 있습니다. 폰트가 없으면 시스템이 쓰기 화면을 엽니다.

## 화면 구성

| 영역 | 내용 |
|------|------|
| 좌측 | 글리프 목록. 한 줄에 10글자를 표시합니다. 한글 11,172자와 영문, 숫자, 기호를 포함합니다 |
| 중앙 | 선택한 글자의 큰 미리보기 |
| 우측 | 원본 필기, 글리프 설정, 전체 여백, 일괄 작업 버튼 |
| 상단 | 모드 전환, 실행 취소, 다시 실행, 변경 적용 |

## 기본 흐름

1. 사용자가 미리보기에서 **고급 편집**을 누릅니다.
2. 시스템이 편집 화면을 열고 `가`를 선택합니다.
3. 사용자가 글리프 목록에서 보정할 글자를 누릅니다.
4. 글자를 빨리 찾으려면 사용자가 검색 칸에 글자를 1개 입력합니다.
5. 시스템이 중앙에 선택한 글자를 크게 표시합니다.
6. 사용자가 우측의 값을 바꿉니다.

| 항목 | 입력 |
|------|------|
| 왼쪽 여백 | 숫자 |
| 오른쪽 여백 | 숫자 |
| 높이 | 숫자 |
| 크기 | 배율. 0.1 이상, 0.05 단위 |
| 회전 | 각도(도) |

7. 시스템이 중앙 미리보기에 변경을 즉시 반영합니다.
8. 시스템이 보정한 글자를 목록에서 다른 색으로 표시합니다. 우측 제목에 "N개 수정됨"이 표시됩니다.
9. 사용자가 **변경 적용**을 눌러 폰트를 다시 생성합니다. 이 단계는 UC-09입니다.

## 대안 흐름 A: 여러 글자를 한 번에 보정

1. 사용자가 글자 하나를 누릅니다.
2. 사용자가 `Shift`를 누른 채 다른 글자를 누릅니다. 시스템이 두 글자 사이의 범위를 선택합니다.
3. 또는 사용자가 `Ctrl`(Mac은 `⌘`)을 누른 채 글자를 누릅니다. 시스템이 그 글자를 선택에 추가하거나 선택에서 제외합니다.
4. 사용자가 값을 입력합니다.
5. 시스템이 선택한 모든 글자에 같은 값을 적용합니다. 글자마다 값이 다른 항목에는 "다름"이 표시됩니다.
6. 사용자가 **선택 높이 맞추기**를 누르면 시스템이 선택한 글자의 높이를 가장 높은 글자에 맞춥니다.

## 대안 흐름 B: 전체 여백 조정

1. 사용자가 "전체 여백"에서 왼쪽, 오른쪽, 높이 값을 입력합니다.
2. 시스템이 모든 글자에 이 값을 적용합니다. 적용은 다음 생성에서 반영됩니다.

## 대안 흐름 C: 보정값 되돌리기

| 동작 | 결과 |
|------|------|
| 실행 취소, 다시 실행 | 보정 변경을 최대 50단계까지 되돌리거나 다시 적용합니다 |
| 선택 초기화 | 선택한 글자의 보정값을 삭제합니다 |
| 모든 글리프 초기화 | 모든 글자의 보정값을 삭제합니다 |

## 대안 흐름 D: 원본 필기 확인

1. 사용자가 글자 1개를 선택합니다.
2. 우측 "원본 필기"에 그 글자를 만든 자모의 목록이 표시됩니다. 예: "초성 ㄱ"입니다.
3. 다른 문맥에서 가져온 자모에는 "다른 문맥에서 파생"이 붙습니다. 겹받침에는 "겹받침 합성"이 붙습니다.
4. 사용자가 항목을 누르면 시스템이 쓰기 화면에서 원본 칸을 엽니다. UC-04의 대안 흐름 B를 참고하십시오.
5. 원본이 없는 자모는 "원본 없음"으로 표시됩니다. 사용자는 이 항목을 누를 수 없습니다.

## 사후 조건

- 시스템이 보정값을 프로젝트에 저장하고 폰트를 "변경됨"으로 표시합니다.
- 변경 적용을 실행하기 전에는 다운로드할 파일에 보정값이 반영되지 않습니다.
