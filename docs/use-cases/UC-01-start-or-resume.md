# UC-01 새 프로젝트를 시작하거나 이어서 만든다

- **액터**: 사용자
- **화면**: 홈(`/`)
- **사전 조건**: 사용자가 브라우저에서 OwnChar를 엽니다. 저장된 작업은 있어도 없어도 됩니다.

## 기본 흐름: 처음 시작

1. 사용자가 홈을 엽니다.
2. 시스템이 IndexedDB에서 저장된 프로젝트를 읽습니다. 읽는 동안 "작업을 불러오는 중"을 표시합니다.
3. 저장된 작업이 없으면 시스템이 "새 폰트 시작하기" 버튼과 3단계 안내를 표시합니다.
4. 3단계는 문장 쓰기, 자모 자동 수집, 조합하고 다듬기입니다.
5. 사용자가 **새 폰트 시작하기**를 누릅니다.
6. 시스템이 저장소를 비우고 빈 프로젝트를 만듭니다. 프로젝트 상태는 `writing`입니다.
7. 시스템이 쓰기 화면(`/write`)을 엽니다. 첫 번째 문장이 표시됩니다.

## 대안 흐름 A: 이어서 만들기

- **조건**: 수집한 자모가 1개 이상이거나, 생성된 폰트가 있습니다.

1. 시스템이 **이어서 만들기** 버튼을 추가로 표시합니다.
2. 시스템이 우측에 "현재 작업" 진행 막대를 표시합니다. 막대는 `수집한 개수 / 필수 개수`를 보여 줍니다.
3. 사용자가 **이어서 만들기**를 누릅니다.
4. 폰트가 이미 생성되었으면(`ready`) 시스템이 미리보기(`/preview`)를 엽니다.
5. 폰트가 없으면 시스템이 쓰기 화면(`/write`)을 엽니다.
6. 마지막으로 보던 문장과 쓴 획이 복원됩니다.

## 대안 흐름 B: 처음부터 다시 만들기

1. 저장된 작업이 있는 상태에서 사용자가 **새 폰트 시작하기** 또는 **처음부터 다시 만들기**를 누릅니다.
2. 시스템이 "현재 작업을 지우고 새로 시작할까요?" 확인창을 표시합니다.
3. 사용자가 확인하면 시스템이 저장된 프로젝트를 삭제하고 빈 프로젝트로 `/write`를 엽니다.
4. 사용자가 취소하면 아무 변화도 없습니다.

## 대안 흐름 C: 저장소를 사용할 수 없음

- 시크릿 모드에서는 IndexedDB를 사용할 수 없을 수 있습니다.
- 이 경우 시스템이 빈 프로젝트로 시작합니다. 작업은 가능합니다.
- 새로고침하면 작업이 사라집니다.

## 사후 조건

- 새로 시작한 경우: 수집한 자모가 0개입니다. 설정은 기본값입니다. 폰트 이름은 "OwnChar Font"입니다.
- 이어서 만든 경우: 이전 상태가 그대로 유지됩니다.

## 개발 모드 전용 기능

- `pnpm dev`로 실행하고 `src/dev/sample-project.json` 파일이 있으면 "샘플 데이터로 채우기" 버튼이 표시됩니다.
- 사용자가 확인하면 시스템이 샘플 필기로 프로젝트를 채우고 `/write`를 엽니다.
- 샘플에는 폰트가 없습니다. 사용자가 폰트를 다시 생성해야 합니다.
