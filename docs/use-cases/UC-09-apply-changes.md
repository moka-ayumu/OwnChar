# UC-09 변경을 적용하여 폰트를 다시 생성한다

- **액터**: 사용자
- **화면**: 미리보기(`/preview`), 편집(`/edit`), 생성(`/generate`)
- **사전 조건**: 폰트가 "변경됨" 상태입니다.

## "변경됨" 상태가 되는 경우

| 동작 | 화면 |
|------|------|
| 필기를 추가, 수정 또는 삭제함 | 쓰기 |
| 폰트 이름, 제작자 또는 버전을 바꿈 | 미리보기 |
| 글리프 보정값을 바꿈 | 편집 |
| 전체 여백을 바꿈 | 편집 |
| 조합 설정을 바꿈 | 편집 |

## 기본 흐름: 미리보기에서 적용

1. 시스템이 미리보기 상단에 안내 배너를 표시합니다.
2. 배너는 "필기 또는 폰트 생성 설정이 변경되었습니다."로 시작합니다.
3. 사용자가 **변경 적용**을 누릅니다.
4. 시스템이 생성 화면(`/generate`)을 엽니다.
5. 시스템이 UC-05의 기본 흐름과 같은 방법으로 폰트를 다시 생성합니다.
6. 생성이 끝나면 시스템이 미리보기를 엽니다. 배너가 사라집니다.
7. 사용자가 새 OTF 파일을 내려받습니다. 이 단계는 UC-06입니다.

## 대안 흐름 A: 편집 화면에서 적용

1. 사용자가 편집 화면 상단의 **변경 적용**을 누릅니다.
2. 시스템이 생성 화면을 엽니다.
3. 이후 단계는 기본 흐름의 5번부터 7번까지와 같습니다.

## 대안 흐름 B: 취소와 실패

- 사용자가 생성을 취소하면 시스템이 쓰기 화면을 엽니다. 이전에 생성한 폰트는 유지됩니다.
- 생성이 실패하면 사용자가 **다시 시도**를 누릅니다. UC-05의 대안 흐름 D를 참고하십시오.

## 사후 조건

- 시스템이 새 폰트를 저장하고 모든 "변경됨" 표시를 지웁니다.
- 새 폰트가 이전 폰트를 교체합니다.
