# PG-08 공통 레이아웃

- **적용 범위**: 모든 페이지(PG-01에서 PG-07까지)
- **대응 Use Case**: UC-01, UC-10
- **목적**: 모든 페이지에서 같은 헤더와 화면 크기 안내를 제공합니다.

## 요소

| 요소 | 종류 | 동작 |
|------|------|------|
| 로고 | 링크 | PG-01을 엽니다 |
| 도움말 | 링크 | PG-07을 엽니다 |
| GitHub | 외부 링크 | 새 탭에서 저장소를 엽니다 |
| 불러오기 안내 | 표시 | 저장된 작업을 읽는 동안 「작업을 불러오는 중」을 표시합니다. 읽기가 끝나면 페이지 내용을 표시합니다 |
| 화면 크기 안내 | 표시 | 화면이 휴대폰 크기이면 「더 넓은 화면이 필요해요」를 표시합니다. 태블릿 또는 데스크톱을 사용하라고 알립니다 |

## 규칙

- 헤더에 계정, 프로젝트 이름, 저장 표시를 넣지 않습니다. 계정과 저장 버튼이 없기 때문입니다.
- 시스템은 저장된 작업을 읽기 전에 페이지 내용을 표시하지 않습니다.
