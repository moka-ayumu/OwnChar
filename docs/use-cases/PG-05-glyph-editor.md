# PG-05 글리프 편집 페이지

- **경로**: `/edit`
- **대응 Use Case**: UC-07, UC-09
- **목적**: 사용자가 글자별로 여백, 높이, 크기, 회전을 보정합니다.

## 진입 조건

- PG-04에서 **고급 편집**을 누릅니다.
- PG-02에서 글리프에서 온 상태로 **기존 폰트 미리보기 · 편집**을 누릅니다. 이때 시스템이 그 글리프를 선택합니다.
- PG-06에서 **글리프 편집**을 누릅니다.
- 생성된 폰트가 없으면 시스템이 PG-02를 엽니다.

## 기능 영역

| 영역             | 기능                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| 사이드 영역      | 수정한 글리프 개수를 보여 주고, 편집 방식을 고르고, 보정 변경을 되돌리고, 다른 페이지로 이동하고, 변경을 적용합니다 |
| 글리프 목록 영역 | 글자를 검색하고, 글자 종류와 조합 조건을 고르고, 글자를 선택합니다                                                  |
| 미리보기 영역    | 선택한 글자를 크게 보여 주고, 여백과 높이를 선으로 조정합니다                                                       |
| 설정 영역        | 원본 필기, 글리프 보정값, 전체 여백, 일괄 작업을 제공합니다                                                         |

## 요소

### 사이드 영역

PG-05와 PG-06은 같은 사이드 영역을 사용합니다.

| 요소               | 종류        | 동작                                                           |
| ------------------ | ----------- | -------------------------------------------------------------- |
| 수정된 글리프 개수 | 표시        | 보정값이 있는 글리프의 개수를 보여 줍니다                      |
| 글리프 편집        | 모드 전환   | PG-05를 엽니다                                                 |
| 한글 조합 설정     | 모드 전환   | PG-06을 엽니다                                                 |
| 실행 취소          | 아이콘 버튼 | 마지막 보정 변경을 취소합니다. 기록이 없으면 비활성입니다      |
| 다시 실행          | 아이콘 버튼 | 취소한 보정 변경을 다시 적용합니다. 기록이 없으면 비활성입니다 |
| 미리보기           | 링크        | PG-04를 엽니다                                                 |
| 글자 다시 쓰기     | 링크        | PG-02를 엽니다                                                 |
| 변경 적용          | 버튼        | PG-03을 엽니다. 사이드 영역의 맨 아래에 둡니다                 |

기록은 최대 50단계입니다.

### 글리프 목록 영역

| 요소                  | 종류           | 동작                                                                                                                                        |
| --------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 검색 입력             | 텍스트 입력    | 글자 1개를 입력하면 그 글자만 목록에 표시합니다. 입력이 없으면 글자 종류의 글자를 표시합니다                                                |
| 글자 종류             | 선택 버튼 4개  | 한글, 자모, 영문, 숫자·기호 중 하나의 목록을 표시합니다                                                                                     |
| 한글 보기             | 선택 버튼 2개  | 한글 종류에서 조합별 또는 전체 보기를 고릅니다. 기본은 조합별입니다                                                                         |
| 모음 형태             | 선택 버튼 3개  | 세로 모음, 가로 모음, 혼합 모음 중 하나를 누르면 그 모음 전체를 중성 조건으로 정합니다. 다시 누르면 해제합니다                              |
| 초성, 중성, 받침 조건 | 토글 버튼 목록 | 고른 자모를 모두 가진 음절만 목록에 표시합니다. 한 부분에서 고른 것이 없으면 그 부분은 모든 자모를 허용합니다. 받침에는 「없음」이 있습니다 |
| 조건 해제             | 버튼           | 세 조건을 모두 비웁니다                                                                                                                     |
| 결과 개수             | 표시           | 조건에 맞는 음절의 개수를 보여 줍니다                                                                                                       |
| 모두 선택             | 버튼           | 조건에 맞는 음절을 모두 선택합니다. 조건이 없으면 비활성입니다                                                                              |
| 선택 개수             | 표시           | 선택한 글자의 개수를 보여 줍니다                                                                                                            |
| 글리프                | 버튼 목록      | 선택한 종류의 글자를 사용자의 폰트로 표시합니다. 열릴 때 선택한 글자의 위치로 이동합니다                                                    |

글리프 선택 방법은 다음과 같습니다.

| 입력                   | 결과                                                                             |
| ---------------------- | -------------------------------------------------------------------------------- |
| 클릭                   | 그 글자 하나만 선택합니다                                                        |
| `Shift` + 클릭         | 기준 글자부터 클릭한 글자까지 선택합니다                                         |
| `Ctrl` 또는 `⌘` + 클릭 | 그 글자를 선택에 추가하거나 선택에서 제외합니다. 마지막 하나는 제외하지 않습니다 |
| 방향키                 | 선택을 이웃 글자로 옮깁니다                                                      |
| `Shift` + 방향키       | 기준 글자부터 이웃 글자까지 선택합니다                                           |

보정한 글리프는 목록에서 구별해 표시합니다.

### 미리보기 영역

| 요소          | 종류 | 동작                                                                                                 |
| ------------- | ---- | ---------------------------------------------------------------------------------------------------- |
| 선택한 글자   | 표시 | 현재 폰트의 글자와 변경 후의 글자를 겹쳐 보여 줍니다. 여러 글자를 선택하면 선택한 개수를 보여 줍니다 |
| 왼쪽 여백선   | 끌기 | 글자 1개를 선택했을 때 좌우로 끌어 왼쪽 여백을 정합니다                                              |
| 오른쪽 여백선 | 끌기 | 글자 1개를 선택했을 때 좌우로 끌어 오른쪽 여백을 정합니다                                            |
| 높이선        | 끌기 | 글자 1개를 선택했을 때 위아래로 끌어 높이를 정합니다                                                 |

끌기는 손을 뗄 때 실행 취소 한 단계로 기록합니다. 화면 폭이 1100px 이하여도 미리보기 영역은 사라지지 않습니다.

### 설정 영역

| 요소                          | 종류          | 동작                                                                                               | 범위                |
| ----------------------------- | ------------- | -------------------------------------------------------------------------------------------------- | ------------------- |
| 원본 필기 목록                | 버튼 목록     | 글자 1개를 선택했을 때 그 글자를 만든 자모를 보여 줍니다. 항목을 누르면 PG-02에서 원본 칸을 엽니다 |                     |
| 원본 없음 항목                | 표시          | 원본이 없는 자모를 보여 줍니다. 누를 수 없습니다                                                   |                     |
| 왼쪽 여백                     | 숫자 입력     | 선택한 글자의 왼쪽 여백을 정합니다                                                                 |                     |
| 오른쪽 여백                   | 숫자 입력     | 선택한 글자의 오른쪽 여백을 정합니다                                                               |                     |
| 높이                          | 숫자 입력     | 선택한 글자의 높이를 정합니다                                                                      |                     |
| 크기                          | 숫자 입력     | 선택한 글자의 배율을 정합니다                                                                      | 0.1 이상, 0.05 단위 |
| 회전                          | 숫자 입력     | 선택한 글자의 각도를 정합니다                                                                      |                     |
| 전체 여백(왼쪽, 오른쪽, 높이) | 숫자 입력 3개 | 모든 글자에 적용하는 값을 정합니다                                                                 |                     |
| 높이 맞추기                   | 버튼          | 선택한 글자의 높이를 가장 높은 글자에 맞춥니다. 글자를 둘 이상 선택해야 활성입니다                 |                     |
| 선택 초기화                   | 버튼          | 선택한 글자의 보정값을 삭제합니다                                                                  |                     |
| 모든 글리프 초기화            | 버튼          | 확인 대화상자를 연 뒤 모든 글자의 보정값을 삭제합니다. 보정한 글자가 없으면 비활성입니다           |                     |

여러 글자를 선택했을 때 값이 다른 항목은 빈 칸으로 두고 「다름」을 표시합니다.

## 상태

| 상태              | 표시                                                      |
| ----------------- | --------------------------------------------------------- |
| 글자 1개 선택     | 보정값과 원본 필기 목록 표시                              |
| 글자 여러 개 선택 | 선택 개수와 공통 보정 입력 표시. 원본 필기 안내 문구 표시 |
| 검색 결과 없음    | 목록이 비어 있음                                          |
