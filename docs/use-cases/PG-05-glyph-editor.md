# PG-05 글리프 편집 페이지

- **경로**: `/edit`
- **대응 Use Case**: UC-07, UC-09
- **목적**: 사용자가 글자별로 여백, 높이, 크기, 회전을 보정합니다.

## 진입 조건

- PG-04에서 **고급 편집**을 누릅니다.
- PG-02에서 글리프에서 온 상태로 **기존 폰트 미리보기 · 편집**을 누릅니다. 이때 시스템이 그 글리프를 선택합니다.
- PG-06에서 **글리프 편집**을 누릅니다.
- 생성된 폰트가 없으면 시스템이 PG-02를 엽니다.

## 기능 영역

| 영역 | 기능 |
|------|------|
| 상단 영역 | 다른 페이지로 이동하고, 보정 변경을 되돌리고, 변경을 적용합니다 |
| 글리프 목록 영역 | 글자를 검색하고 선택합니다 |
| 미리보기 영역 | 선택한 글자를 크게 보여 줍니다 |
| 설정 영역 | 원본 필기, 글리프 보정값, 전체 여백, 일괄 작업을 제공합니다 |

## 요소

### 상단 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 미리보기 | 링크 | PG-04를 엽니다 |
| 글자 다시 쓰기 | 링크 | PG-02를 엽니다 |
| 한글 조합 설정 | 모드 전환 | PG-06을 엽니다 |
| 실행 취소 | 아이콘 버튼 | 마지막 보정 변경을 취소합니다. 기록이 없으면 비활성입니다 |
| 다시 실행 | 아이콘 버튼 | 취소한 보정 변경을 다시 적용합니다. 기록이 없으면 비활성입니다 |
| 변경 적용 | 버튼 | PG-03을 엽니다 |

기록은 최대 50단계입니다.

### 글리프 목록 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 검색 입력 | 텍스트 입력 | 글자 1개를 입력하면 그 글자만 목록에 표시합니다. 입력이 없으면 전체를 표시합니다 |
| 선택 개수 | 표시 | 선택한 글자의 개수를 보여 줍니다 |
| 글리프 | 버튼 목록 | 한글 11,172자와 영문, 숫자, 기호를 사용자의 폰트로 표시합니다 |

글리프 선택 방법은 다음과 같습니다.

| 입력 | 결과 |
|------|------|
| 클릭 | 그 글자 하나만 선택합니다 |
| `Shift` + 클릭 | 마지막 선택 글자부터 클릭한 글자까지 선택합니다 |
| `Ctrl` 또는 `⌘` + 클릭 | 그 글자를 선택에 추가하거나 선택에서 제외합니다 |

보정한 글리프는 목록에서 구별해 표시합니다.

### 미리보기 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 선택한 글자 | 표시 | 현재 보정값을 반영하여 글자를 보여 줍니다. 여러 글자를 선택하면 선택한 개수를 보여 줍니다 |

### 설정 영역

| 요소 | 종류 | 동작 | 범위 |
|------|------|------|------|
| 원본 필기 목록 | 버튼 목록 | 글자 1개를 선택했을 때 그 글자를 만든 자모를 보여 줍니다. 항목을 누르면 PG-02에서 원본 칸을 엽니다 | |
| 원본 없음 항목 | 표시 | 원본이 없는 자모를 보여 줍니다. 누를 수 없습니다 | |
| 왼쪽 여백 | 숫자 입력 | 선택한 글자의 왼쪽 여백을 정합니다 | |
| 오른쪽 여백 | 숫자 입력 | 선택한 글자의 오른쪽 여백을 정합니다 | |
| 높이 | 숫자 입력 | 선택한 글자의 높이를 정합니다 | |
| 크기 | 숫자 입력 | 선택한 글자의 배율을 정합니다 | 0.1 이상, 0.05 단위 |
| 회전 | 숫자 입력 | 선택한 글자의 각도를 정합니다 | |
| 수정된 글리프 개수 | 표시 | 보정한 글리프의 개수를 보여 줍니다 | |
| 전체 여백(왼쪽, 오른쪽, 높이) | 숫자 입력 3개 | 모든 글자에 적용하는 값을 정합니다 | |
| 선택 높이 맞추기 | 버튼 | 선택한 글자의 높이를 가장 높은 글자에 맞춥니다 | |
| 선택 초기화 | 버튼 | 선택한 글자의 보정값을 삭제합니다 | |
| 모든 글리프 초기화 | 버튼 | 모든 글자의 보정값을 삭제합니다 | |

여러 글자를 선택했을 때 값이 다른 항목은 빈 칸으로 두고 「다름」을 표시합니다.

## 상태

| 상태 | 표시 |
|------|------|
| 글자 1개 선택 | 보정값과 원본 필기 목록 표시 |
| 글자 여러 개 선택 | 선택 개수와 공통 보정 입력 표시. 원본 필기 안내 문구 표시 |
| 검색 결과 없음 | 목록이 비어 있음 |
