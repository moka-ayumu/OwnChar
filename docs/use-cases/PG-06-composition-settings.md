# PG-06 조합 설정 페이지

- **경로**: `/edit`의 조합 설정 모드
- **대응 Use Case**: UC-08, UC-09
- **목적**: 사용자가 자모를 음절로 합치는 규칙을 바꾸고, 결과를 즉시 확인합니다.

## 진입 조건

- PG-05에서 **한글 조합 설정**을 누릅니다.

## 기능 영역

| 영역 | 기능 |
|------|------|
| 사이드 영역 | PG-05와 같은 사이드 영역을 사용합니다 |
| 미리보기 영역 | 대표 글자를 현재 필기와 설정으로 즉시 조합하여 보여 줍니다 |
| 설정 영역 | 크기, 보정, 정렬 묶음으로 조합 설정 값을 정합니다 |

## 요소

### 사이드 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 글리프 편집 | 모드 전환 | PG-05를 엽니다 |
| 변경 적용 | 버튼 | PG-03을 엽니다 |

PG-05의 다른 사이드 요소(수정된 글리프 개수, 미리보기 링크, 글자 다시 쓰기 링크, 실행 취소, 다시 실행)도 같은 동작으로 제공합니다.

### 미리보기 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 독립 자모 카드 | 표시 | `ㅇ`, `ㅜ`를 보여 줍니다 |
| 음절 카드 | 표시 | `가`, `각`, `갃`, `까`, `고`, `곡`, `과`, `곽`, `괘`, `좋`, `루`를 보여 줍니다 |
| 문맥형 벌 수 | 표시 | 음절 카드마다 사용한 초성, 중성, 종성의 벌 수를 보여 줍니다. 카드의 설명은 카드에 올린 툴팁으로 보여 줍니다 |
| 즉시 반영 안내 | 툴팁 | 조합 설정 모드에서 변경 적용 버튼에 올립니다. 미리보기는 즉시 바뀌고, OTF 파일은 변경 적용 후에 바뀐다고 알립니다 |

### 설정 영역

| 요소 | 종류 | 범위 | 효과 |
|------|------|------|------|
| 단일 초성 크기 | 숫자 입력 | 0.5에서 1.2까지 | 초성이 하나일 때 차지하는 비율 |
| 모음 크기 | 숫자 입력 | 0.5에서 1.2까지 | 모음이 차지하는 비율 |
| 받침 크기 | 숫자 입력 | 0.5에서 1.2까지 | 받침이 차지하는 비율 |
| 손떨림 보정 강도 | 슬라이더 | 0에서 1까지 | 획의 떨림과 끝의 갈고리를 보정합니다. PG-02의 같은 설정과 연동합니다 |
| 합성 쌍자음 간격 | 슬라이더 | 0에서 1까지 | 쓰지 않은 쌍자음을 단자음 둘로 만들 때 두 자음의 간격 |
| 한글 음절 정규화 | 슬라이더 | 0에서 1까지 | 음절의 크기를 대표 크기에 맞춥니다 |
| 자모 정규화 | 슬라이더 | 0에서 1까지 | 독립 자모의 크기를 맞춥니다 |
| 영문 정규화 | 슬라이더 | 0에서 1까지 | 영문의 크기를 맞춥니다 |
| 단독 자모 크기 | 슬라이더 | 10%에서 100%까지 | 독립 자모를 그 자모가 조합 글자 안에서 갖는 크기에 맞추는 비율 |
| 수직 정렬 | 슬라이더 | 0에서 1까지 | 글자 역할별 기준 높이에 맞추는 강도 |
| 글자 가로폭 | 선택 버튼 2개 | 가변 폭, 고정 폭 | 글자 폭의 방식 |
| 조합 기본값 복원 | 버튼 | | 모든 조합 설정을 기본값으로 되돌립니다 |

슬라이더는 현재 값을 백분율로, 숫자 입력은 현재 값을 숫자로 함께 표시합니다. 초성·모음·받침 크기 입력이 1.2를 넘으면 1.2로 정합니다.

크기 다이얼(글자 폭, 초성 크기, 중성 크기, 종성 크기)은 PG-04에서 정합니다. 미리보기 영역의 카드는 다이얼 값을 반영합니다. **조합 기본값 복원**은 다이얼도 기본값으로 되돌립니다.

## 상태

| 상태 | 표시 |
|------|------|
| 설정이 기본값임 | 모든 값이 기본값 |
| 설정을 바꿈 | 미리보기가 즉시 바뀌고, 폰트가 「변경됨」으로 표시됨 |
