# UC-02 문장을 쓰면서 자모를 수집한다

- **액터**: 사용자
- **화면**: 쓰기(`/write`)
- **사전 조건**: 프로젝트가 시작되어 있습니다. 프로젝트가 없으면 시스템이 홈으로 이동합니다.

## 화면 구성

| 영역 | 내용 |
|------|------|
| 좌측 패널 | 로고(사이드바 여닫기), 전체 수집률, 연습 문장 목록, 이전 문장 버튼, 다음 문장 버튼. 닫으면 아이콘 열만 남습니다 |
| 중앙 | 왼쪽에 고정된 도구 아이콘 열, 현재 문장(오른쪽 끝에 문장 진행 표시, 도움말, GitHub), 글자 칸 캔버스, 쓰는 칸 옆의 칸 팝오버 |

연습 문장은 모두 12개입니다.

1. 한글 문장 9개
2. 영문 대문자 문장 1개
3. 영문 소문자 문장 1개
4. 숫자와 기호 1개

한글 문장 9개에는 필수 문맥형 자모가 모두 포함되어 있습니다.

## 기본 흐름

1. 사용자가 쓰기 화면을 엽니다.
2. 시스템이 현재 문장을 큰 글씨로 표시합니다. 문장의 글자마다 캔버스에 칸을 하나 만듭니다.
3. 각 칸에는 해당 글자가 연한 색으로 표시됩니다.
4. 사용자가 도구 열의 **쓰기 설정**에서 **글자 칸 크기**를 정합니다. 범위는 112 px에서 184 px까지입니다.
5. 사용자가 같은 창에서 **획 굵기**(1에서 5까지)와 **손떨림 보정**(0에서 1까지)을 정합니다.
6. 사용자가 첫 번째 칸에 획을 씁니다.
7. 펜에 필압이 있으면 시스템이 필압을 굵기에 반영합니다. 마우스는 일정한 굵기로 그립니다.
8. 시스템이 획을 **시작한 칸**의 글자에 귀속시킵니다. 획이 칸 밖으로 나가도 같습니다.
9. 시스템이 칸 안의 획을 쓴 순서대로 자모에 나누어 담습니다. 한글 음절의 순서는 초성, 중성, 종성입니다.
10. 자모마다 예상 획수가 있습니다. 예: ㄱ은 1획, ㅋ은 2획, ㅂ은 4획입니다. 획수를 채우면 다음 자모로 넘어갑니다.
11. 시스템이 쓰는 칸 옆의 팝오버에 그 칸의 자모와 남은 획수를 보여 줍니다. 칸의 자모를 모두 쓰면 칸의 배경색이 바뀝니다. 빈칸은 그 뒤의 칸에 첫 획이 들어오면 배경색이 바뀝니다.
12. 사용자가 다음 글자들을 같은 방법으로 씁니다.
13. 시스템이 수집률과 문장별 자모 개수를 갱신합니다.
14. 시스템이 획이 바뀐 뒤 250 ms가 지나면 문장 단위로 저장합니다. 자세한 내용은 UC-10에 있습니다.

## 고정 자모와 자리 안내

- 다른 칸에서 이미 수집한 자모는 칸에 회색 가이드로 표시됩니다. 사용자는 수집하지 않은 자모만 쓰면 됩니다.
- 쓰지 않은 자모의 자리는 점선 상자로 표시됩니다. **자리 안내** 버튼이 이 표시를 켜고 끕니다.
- 시스템이 자리 안내 설정을 이 기기에 기억합니다.
- 칸에 첫 획을 쓰면 시스템이 그 칸의 가이드를 고정합니다. 다른 자모를 수집해도 가이드는 바뀌지 않습니다.

## 파생 수집

- 사용자가 문맥형 자모를 쓰면 시스템이 같은 자모를 독립 자음 또는 독립 모음으로도 등록합니다. 예: `가`의 ㄱ은 독립 ㄱ으로도 등록됩니다.
- 더 적합한 형태가 이미 있으면 시스템이 덮어쓰지 않습니다. 열린 음절형이 우선이고, 종성형이 마지막입니다.
- 겹받침은 필수가 아닙니다. 시스템이 폰트를 생성할 때 단일 받침을 합성합니다.

## 대안 흐름

### 지우개

1. 사용자가 도구를 **지우개**로 바꿉니다.
2. 사용자가 획 위를 문지릅니다.
3. 시스템이 닿은 획을 삭제합니다.
4. 삭제한 획으로 채웠던 자모는 수집에서 빠지고, 그 칸의 완료 표시가 사라집니다.

### 실행 취소와 다시 실행

- 시스템은 현재 문장에서 최대 50단계를 취소할 수 있습니다.

### 문장 모두 지우기

1. 사용자가 휴지통 아이콘(**문장 모두 지우기**)을 누릅니다.
2. 시스템이 현재 문장의 모든 획과 경계를 삭제합니다.
3. 시스템이 이 문장에서 수집한 자모를 수집에서 제외합니다.
4. 다른 문장에서 수집한 자모는 변하지 않습니다.

### 칸 크기 고정

- 획이 1개 이상 있으면 시스템이 슬라이더를 비활성화합니다. 획의 칸 위치를 보존하기 위해서입니다.
- 칸 크기를 바꾸려면 먼저 문장을 모두 지우십시오.

### 영문, 숫자, 기호 문장

- 한 칸이 한 글자입니다. 자모 분리는 없습니다.
- 숫자와 기호는 평소의 위치와 크기로 씁니다.

### 획이 잘못 나뉨

- 시스템이 자모를 잘못 나누면 UC-03의 방법으로 칸 팝오버에서 직접 정합니다.

## 사후 조건

- 시스템이 쓴 획과 칸 배치를 문장 세션에 저장합니다.
- 시스템이 자모별 윤곽을 저장합니다.
- 폰트를 이미 생성한 적이 있으면 시스템이 "필기 변경됨"으로 표시합니다. 이 표시는 UC-09에서 사용합니다.
