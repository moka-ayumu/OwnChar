# UC-03 자모 나누기를 직접 정한다

- **액터**: 사용자
- **화면**: 쓰기(`/write`)의 칸 팝오버
- **배경**: 시스템은 자모마다 정해진 획수로 획을 나눕니다. 사용자가 획을 더 나누어 쓰거나 합쳐 쓰면 추정이 틀릴 수 있습니다. 이 경우 사용자가 칸 팝오버에서 직접 정합니다.

## 기본 흐름

1. 사용자가 칸에 획을 쓰기 시작합니다. 예: `밥` 칸입니다.
2. 시스템이 그 칸의 오른쪽에 칸 팝오버를 엽니다. 마지막 열의 칸에서는 왼쪽에 엽니다.
3. 팝오버의 위쪽에 이 칸에서 수집하는 자모가 탭으로 표시됩니다. 지금 수집하는 자모(초성 ㅂ)가 강조됩니다.
4. 탭 아래에 "초성 ㅂ"과 "남은 획 3"처럼 남은 획수가 표시됩니다. 획을 쓸 때마다 줄어듭니다.
5. 자모의 평소 획수를 채우면 시스템이 수집을 다음 자모(중성 ㅏ)로 옮깁니다. 끝난 자모의 탭에는 완료 표시가 붙습니다.
6. 마지막 자모까지 끝나면 칸의 배경색이 바뀌고 팝오버가 닫힙니다.

## 대안 흐름

### 수집을 미리 끝내기

1. 사용자가 자모를 평소보다 적은 획으로 썼습니다.
2. 사용자가 팝오버 아래의 **ㅂ 완료** 버튼을 누릅니다.
3. 시스템이 가장 최근 획 뒤에 경계를 기록합니다.
4. 이후에 쓰는 획은 다음 자모에 배정됩니다. 강조된 탭도 다음 자모로 바뀝니다.

### 탭으로 수집 옮기기

1. 사용자가 다른 자모의 탭을 누릅니다.
2. 뒤쪽 자모의 탭을 누르면 시스템이 그 앞의 자모를 지금 획에서 끝냅니다.
3. 앞쪽 자모의 탭을 누르면 시스템이 그 자모를 다시 엽니다. 그 뒤에 쓴 획은 모두 그 자모에 다시 속합니다. 이 자모는 평소 획수를 넘어도 닫히지 않고, 사용자가 **완료**를 누를 때 끝납니다. 이때 "다 썼으면 완료해 주세요"가 표시됩니다.
4. 앞 자모에 획이 하나도 없는 탭은 누를 수 없습니다.

### 완료한 칸 다시 열기

1. 사용자가 획이 있는 칸의 오른쪽 아래 글자를 누릅니다.
2. 시스템이 그 칸의 팝오버를 엽니다. 자모를 모두 수집한 칸이면 "수집 완료"가 표시됩니다.
3. 사용자가 탭으로 수집을 옮기거나, **닫기**를 누릅니다.
4. 다른 칸에 획을 쓰면 팝오버는 그 칸으로 옮겨 갑니다.

### 획이 없음

- 지금 수집하는 자모에 획이 없으면 완료 버튼이 비활성화됩니다.

### 나누기의 기준 획을 삭제함

1. 사용자가 경계의 기준이 된 획을 지웁니다.
2. 시스템이 해당 경계를 무효로 처리합니다.
3. 시스템이 팝오버에 경고를 표시합니다. 경고는 "나눠 둔 획이 지워졌어요. 자모가 맞게 나뉘었는지 확인해 주세요."입니다.

### 고정 자모가 있는 칸

- 시스템은 고정 자모를 건너뜁니다.
- 탭에는 칸에서 아직 쓰는 자모만 표시됩니다.

## 사후 조건

- 시스템이 확정한 경계를 문장 세션에 저장합니다. 새로고침한 뒤에도 경계가 유지됩니다.
- 다시 연 자모는 그때까지 쓴 마지막 획에서 끝난 것으로 저장됩니다.
