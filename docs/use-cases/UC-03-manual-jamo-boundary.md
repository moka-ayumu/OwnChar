# UC-03 자모 경계를 직접 지정한다

- **액터**: 사용자
- **화면**: 쓰기(`/write`)의 "자모 경계" 컨트롤
- **배경**: 시스템은 자모마다 정해진 획수로 경계를 추정합니다. 사용자가 획을 더 나누어 쓰거나 합쳐 쓰면 추정이 틀릴 수 있습니다. 이 경우 사용자가 경계를 직접 확정합니다.

## 기본 흐름

1. 사용자가 칸에 획을 쓰기 시작합니다. 예: `밥` 칸입니다.
2. 시스템이 경계 컨트롤을 활성화합니다.
3. 컨트롤에 "밥의 자모 경계"와 "초성 ㅂ 획을 모두 쓴 뒤 완료해 주세요."가 표시됩니다.
4. 사용자가 ㅂ의 획을 모두 씁니다.
5. 사용자가 **밥 · 초성 ㅂ 완료** 버튼을 누릅니다.
6. 시스템이 가장 최근 획 뒤에 경계를 기록합니다.
7. 이후에 쓰는 획은 다음 자모(중성 ㅏ)에 배정됩니다. 안내 문구도 다음 자모로 바뀝니다.
8. 사용자가 나머지 자모를 같은 방법으로 완료합니다.
9. 마지막 자모를 확정하면 "이 칸의 자모 경계가 모두 확정됐어요."가 표시됩니다.

## 대안 흐름

### 경계 되돌리기

1. 사용자가 **경계 되돌리기**를 누릅니다.
2. 시스템이 마지막 경계 1개를 취소합니다.
3. 그 경계 뒤의 획은 앞쪽 자모에 다시 속합니다.

### 획이 없음

- 칸에 획이 없으면 완료 버튼이 비활성화됩니다.
- 안내 문구는 "획을 시작하면 현재 자모를 바로 완료할 수 있어요."입니다.

### 경계 기준 획을 삭제함

1. 사용자가 경계의 기준이 된 획을 지웁니다.
2. 시스템이 해당 경계를 무효로 처리합니다.
3. 시스템이 경고를 표시합니다. 경고는 "경계로 지정한 획이 지워져 이후 자모 경계를 다시 확인해 주세요."입니다.

### 고정 자모가 있는 칸

- 시스템은 고정 자모를 건너뜁니다.
- 경계 대상은 칸에서 아직 쓰는 자모뿐입니다.

## 사후 조건

- 시스템이 확정한 경계를 문장 세션에 저장합니다. 새로고침한 뒤에도 경계가 유지됩니다.
- 시스템이 수집된 자모 띠를 새 경계로 갱신합니다.
