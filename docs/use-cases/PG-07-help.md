# PG-07 도움말 페이지

- **경로**: `/license`
- **대응 Use Case**: UC-10
- **목적**: 사용자가 사용 방법과 데이터 처리 방식, 사용한 라이브러리를 확인합니다.

## 진입 조건

- 사용자가 공통 헤더의 **도움말**을 누릅니다.

## 표시 데이터

| 데이터 | 설명 |
|--------|------|
| 데이터 처리 안내 | 모든 데이터를 브라우저 안에서만 처리하며, 계정과 서버 업로드가 필요 없다고 알립니다 |
| 작성 방법 | 4단계의 번호 목록입니다 |
| 사용한 라이브러리 | 라이브러리 이름과 라이선스 안내입니다 |

작성 방법 4단계는 다음과 같습니다.

1. 기본 자모와 영문, 숫자를 쓰고, 필요하면 문맥형 자모를 추가합니다.
2. 펜 입력은 캔버스 중앙을 넉넉하게 사용합니다. 획이 겹쳐도 됩니다.
3. 모든 글자를 쓰면 시스템이 현대 한글 11,172자를 자동으로 조합합니다.
4. 미리보기와 고급 편집에서 간격, 크기, 위치를 조정하고 OTF 파일을 내려받습니다.
