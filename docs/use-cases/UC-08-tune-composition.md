# UC-08 한글 조합 설정을 조정한다

- **액터**: 사용자
- **화면**: 편집(`/edit`)의 "한글 조합 설정" 모드
- **사전 조건**: 생성된 폰트가 있습니다.
- **목적**: 사용자가 자모를 음절로 합치는 규칙을 바꾸어 글자 전체의 균형을 맞춥니다.

## 기본 흐름

1. 사용자가 편집 화면 상단에서 **한글 조합 설정**을 누릅니다.
2. 시스템이 대표 글자 미리보기를 표시합니다. 시스템은 현재 필기와 설정으로 미리보기를 즉시 조합합니다.
3. 미리보기에는 독립 자모 `ㅇ`, `ㅜ`와 음절 11개가 포함됩니다.
4. 음절은 `가`, `각`, `갃`, `까`, `고`, `곡`, `과`, `곽`, `괘`, `좋`, `루`입니다.
5. 각 음절 카드는 사용한 문맥형의 벌 수를 표시합니다. 예: "초 1벌 · 중 1벌"입니다.
6. 사용자가 우측 패널에서 설정을 바꿉니다.
7. 시스템이 모든 미리보기 카드를 즉시 다시 그립니다. 시스템은 전체 폰트를 다시 생성하지 않습니다.
8. 사용자가 결과에 만족하면 **변경 적용**을 누릅니다. 이 단계는 UC-09입니다.

## 설정 항목

| 항목 | 범위 | 효과 |
|------|------|------|
| 단일 초성 크기 | 0.5에서 1.2까지 | 초성이 하나일 때 음절에서 차지하는 비율 |
| 모음 크기 | 0.5에서 1.2까지 | 음절에서 모음이 차지하는 비율 |
| 받침 크기 | 0.5에서 1.2까지 | 받침 영역에서 받침이 차지하는 비율 |
| 손떨림 보정 강도 | 0에서 1까지 | 0은 원본 획입니다. 1은 떨림과 획 끝의 갈고리를 최대로 보정합니다 |
| 한글 음절 정규화 | 0에서 1까지 | 0은 원본 크기입니다. 1은 필기의 대표 크기에 가장 가깝게 맞춥니다 |
| 자모 정규화 | 0에서 1까지 | 독립 자모의 크기 정규화 |
| 영문 정규화 | 0에서 1까지 | 영문의 크기 정규화 |
| 단독 자모 크기 | 10%에서 100%까지 | 자음과 모음 한 글자를 `가`의 크기 안에 맞추는 비율 |
| 수직 정렬 | 0에서 1까지 | 글자 역할별 기준 높이에 맞추는 강도 |
| 글자 가로폭 | 가변 폭 또는 고정 폭 | 글자마다 폭을 다르게 할지, 같게 할지 정함 |

## 대안 흐름

### 기본값 복원

1. 사용자가 **조합 기본값 복원**을 누릅니다.
2. 시스템이 모든 조합 설정을 기본값으로 되돌립니다.

### 쓰기 화면의 손떨림 보정과 연동

- 쓰기 화면의 손떨림 보정 슬라이더와 이 화면의 손떨림 보정 강도는 같은 설정입니다.
- 한쪽을 바꾸면 다른 쪽도 바뀝니다.

## 사후 조건

- 시스템이 설정을 프로젝트에 저장하고 폰트를 "변경됨"으로 표시합니다.
- 변경 적용을 실행한 뒤에 설정이 OTF 파일에 반영됩니다.
