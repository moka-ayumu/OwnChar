# PG-02 쓰기 페이지

- **경로**: `/write`
- **대응 Use Case**: UC-02, UC-03, UC-04, UC-05(시작 부분), UC-10(자동 저장)
- **목적**: 사용자가 연습 문장을 쓰고, 시스템이 자모를 수집합니다.

## 진입 조건

- PG-01에서 시작하거나 이어서 만듭니다.
- PG-04 또는 PG-05에서 **글자 다시 쓰기**를 누릅니다.
- PG-05에서 글리프의 원본 필기 항목을 누릅니다. 이때 문장과 칸이 지정됩니다.
- PG-03에서 생성을 취소합니다.
- 프로젝트가 없으면 시스템이 PG-01을 엽니다.

## 기능 영역

| 영역 | 기능 |
|------|------|
| 진행 영역 | 전체 수집률과 문장별 수집 상태를 보여 줍니다 |
| 문장 영역 | 현재 문장, 안내 문구, 문장별 수집 개수를 보여 줍니다 |
| 도구 영역 | 쓰기 도구와 입력 설정을 제공합니다 |
| 캔버스 영역 | 문장의 글자마다 칸을 하나 표시하고, 사용자의 획을 입력받습니다 |
| 경계 영역 | 자모 경계를 직접 지정합니다 |
| 수집 목록 영역 | 현재 문장에서 수집한 자모를 보여 줍니다 |
| 이동 영역 | 문장을 이동하고 폰트 생성을 시작합니다 |

## 요소

### 진행 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 전체 수집률 | 표시와 막대 | `수집한 개수 / 필수 개수`를 보여 줍니다 |
| 문장 목록 | 버튼 목록 | 문장 12개를 보여 줍니다. 항목마다 번호, 제목, `수집한 개수 / 필요 개수`를 표시합니다. 완료한 문장은 번호 대신 완료 표시를 합니다. 항목을 누르면 그 문장을 엽니다 |

### 도구 영역

| 요소 | 종류 | 동작 | 범위 |
|------|------|------|------|
| 펜 | 선택 버튼 | 쓰기 도구를 펜으로 정합니다 | |
| 지우개 | 선택 버튼 | 쓰기 도구를 지우개로 정합니다. 닿은 획을 삭제합니다 | |
| 획 굵기 | 슬라이더 | 새 획의 굵기를 정합니다 | 1에서 5까지 |
| 손떨림 보정 | 슬라이더 | 획의 떨림 보정 강도를 정합니다. PG-06의 같은 설정과 연동합니다 | 0에서 1까지 |
| 글자 칸 크기 | 슬라이더 | 칸 크기를 정합니다. 획이 1개 이상 있으면 비활성화합니다 | 112 px에서 184 px까지 |
| 자리 안내 | 켬/끔 버튼 | 쓰지 않은 자모의 자리를 점선 상자로 표시하거나 숨깁니다. 이 기기에 저장합니다 | |
| 실행 취소 | 아이콘 버튼 | 현재 문장의 마지막 변경을 취소합니다 | 최대 50단계 |
| 다시 실행 | 아이콘 버튼 | 취소한 변경을 다시 적용합니다 | 최대 50단계 |
| 문장 모두 지우기 | 아이콘 버튼 | 현재 문장의 모든 획과 경계를 삭제합니다 | |

### 캔버스 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 글자 칸 | 입력 영역 | 획을 입력받습니다. 획은 시작한 칸의 글자에 귀속됩니다 |
| 고정 자모 | 표시 | 이미 수집한 자모를 회색 가이드로 칸에 표시합니다 |
| 자리 안내 상자 | 표시 | 쓰지 않은 자모의 자리를 점선으로 표시합니다 |
| 원본 칸 강조 | 표시 | PG-05에서 지정한 칸을 강조하고 그 위치까지 스크롤합니다 |

### 경계 영역

| 요소 | 종류 | 동작 | 비활성 조건 |
|------|------|------|-------------|
| 경계 안내 | 표시 | 현재 칸의 글자와 다음에 완료할 자모를 보여 줍니다 | |
| 자모 완료 | 버튼 | 가장 최근 획 뒤에 경계를 기록합니다. 라벨은 「글자 · 역할 자모 완료」입니다 | 칸에 획이 없을 때. 모든 자모를 확정했을 때 |
| 경계 되돌리기 | 버튼 | 마지막 경계 1개를 취소합니다 | 경계가 없을 때 |
| 경계 경고 | 알림 | 경계의 기준 획을 삭제하면 다시 확인하라고 알립니다 | 경고가 없으면 숨김 |

### 수집 목록 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 자모 카드 | 표시 | 수집한 자모의 미리보기, 글자, 자모, 역할을 보여 줍니다 |
| 빈 목록 안내 | 표시 | 수집한 자모가 없을 때 첫 획을 쓰라고 안내합니다 |

### 이동 영역

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 이전 문장 | 버튼 | 앞 문장을 엽니다 | 첫 문장에서는 비활성 |
| 다음 문장 | 버튼 | 다음 문장을 엽니다 | 마지막 문장이 아닐 때 |
| 폰트 만들기 | 버튼 | 폰트 생성을 시작합니다 | 마지막 문장일 때 |
| 지금 폰트 만들기 | 링크 버튼 | 폰트 생성을 시작합니다 | 마지막 문장이 아닐 때 |
| 기존 폰트 미리보기 · 편집 | 버튼 | 글리프에서 온 경우 PG-05를, 아니면 PG-04를 엽니다 | 생성된 폰트가 있을 때 |

## 대화상자

| 이름 | 표시 시점 | 내용 | 선택 |
|------|-----------|------|------|
| 수집하지 않은 글자 | 필수 항목이 비어 있는 상태에서 생성을 시작할 때 | 기본 글자, 문맥형, 기호의 빈 개수와 글자 목록 | 계속 작성하기: 닫습니다. 그래도 생성하기: 생성을 계속합니다 |
| 기존 글리프 보정 | 필기를 변경했고 보정한 글리프가 있을 때 | 보정한 글리프의 개수 | 보정 유지하고 재합성. 기존 보정 삭제 후 재합성. 취소 |

## 자동 저장

- 시스템이 획을 바꾼 뒤 250 ms가 지나면 현재 문장을 저장합니다.
- 시스템이 문장을 이동할 때 현재 문장의 번호를 저장합니다.

## 상태

| 상태 | 표시 |
|------|------|
| 획이 없음 | 칸 크기 조정 가능. 수집 목록에 안내 표시 |
| 획이 있음 | 칸 크기 고정 |
| 해당 문장을 이전에 썼음 | 저장된 획, 경계, 가이드를 복원 |
