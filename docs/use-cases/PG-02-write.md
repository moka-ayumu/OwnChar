# PG-02 쓰기 페이지

- **경로**: `/write`
- **대응 Use Case**: UC-02, UC-03, UC-04, UC-05(시작 부분), UC-10(자동 저장)
- **목적**: 사용자가 연습 문장을 쓰고, 시스템이 자모를 수집합니다.

## 진입 조건

- PG-01에서 시작하거나 이어서 만듭니다.
- PG-04 또는 PG-05에서 **글자 다시 쓰기**를 누릅니다.
- PG-05에서 글리프의 원본 필기 항목을 누릅니다. 이때 문장과 칸이 지정됩니다.
- PG-03에서 생성을 취소합니다.
- 프로젝트가 없으면 시스템이 PG-01을 엽니다.

## 기능 영역

| 영역 | 기능 |
|------|------|
| 진행 영역 | 로고와 사이드바 여닫기, 전체 수집률, 문장별 수집 상태를 보여 줍니다. 닫으면 아이콘만 있는 좁은 열이 됩니다 |
| 도구 영역 | 캔버스 왼쪽에 고정된 아이콘 버튼 열입니다. 캔버스를 스크롤해도 움직이지 않습니다 |
| 문장 영역 | 현재 문장만 보여 줍니다. 오른쪽 끝에 이 문장의 원형 진행 표시와 도움말, GitHub 링크가 있습니다 |
| 캔버스 영역 | 도구 영역의 오른쪽 전체입니다. 문장의 글자마다 칸을 하나 표시하고, 사용자의 획을 입력받습니다 |
| 칸 팝오버 | 쓰고 있는 칸의 옆에 떠서, 그 칸에서 수집하는 자모와 남은 획수를 보여 주고 수집 대상을 바꿉니다 |
| 이동 영역 | 문장을 이동하고 폰트 생성을 시작합니다 |

## 요소

### 진행 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 로고 아이콘 | 버튼 | 사이드바를 닫거나 엽니다. 상태를 이 기기에 저장합니다 |
| OwnChar | 링크 | 사이드바가 열려 있을 때 로고 아이콘 옆에 표시합니다. PG-01을 엽니다 |
| 전체 수집률 | 표시와 막대 | `수집한 개수 / 필수 개수`를 보여 줍니다. 사이드바를 닫으면 세로 막대가 되고, 개수는 올려 두면 표시합니다 |
| 문장 목록 | 버튼 목록 | 문장 12개를 보여 줍니다. 항목마다 원형 진행 표시와 제목을 표시합니다. 완료한 문장은 원형 진행 표시 대신 완료 표시를 합니다. 항목에 올려 두면 `수집한 개수 / 필요 개수`를 표시합니다. 항목을 누르면 그 문장을 엽니다 |

### 도구 영역

위에서 아래로 펜, 지우개, 실행 취소, 다시 실행, 문장 모두 지우기 순서입니다. 쓰기 설정은 열의 맨 아래에 있습니다. 모든 버튼은 아이콘만 표시하고, 이름은 도구 설명과 접근성 라벨로 제공합니다.

| 요소 | 종류 | 동작 | 범위 |
|------|------|------|------|
| 펜 | 선택 버튼 | 쓰기 도구를 펜으로 정합니다 | |
| 지우개 | 선택 버튼 | 쓰기 도구를 지우개로 정합니다. 닿은 획을 삭제합니다 | |
| 실행 취소 | 아이콘 버튼 | 현재 문장의 마지막 변경을 취소합니다 | 최대 50단계 |
| 다시 실행 | 아이콘 버튼 | 취소한 변경을 다시 적용합니다 | 최대 50단계 |
| 문장 모두 지우기 | 아이콘 버튼 | 현재 문장의 모든 획과 자모 나누기를 삭제합니다 | |
| 쓰기 설정 | 아이콘 버튼 | 버튼 옆에 설정 창을 엽니다. 창 밖을 누르거나 Esc를 누르면 닫습니다 | |
| 글자 칸 크기 | 슬라이더(쓰기 설정) | 칸 크기를 정합니다. 획이 1개 이상 있으면 비활성화하고, 올려 두면 이유를 표시합니다 | 112 px에서 184 px까지 |
| 획 굵기 | 슬라이더(쓰기 설정) | 새 획의 굵기를 정합니다 | 1에서 5까지 |
| 손떨림 보정 | 슬라이더(쓰기 설정) | 획의 떨림 보정 강도를 정합니다. PG-06의 같은 설정과 연동합니다 | 0에서 1까지 |
| 자리 안내 | 켬/끔 버튼(쓰기 설정) | 쓰지 않은 자모의 자리를 점선 상자로 표시하거나 숨깁니다. 이 기기에 저장합니다 | |


### 캔버스 영역

| 요소 | 종류 | 동작 |
|------|------|------|
| 글자 칸 | 입력 영역 | 획을 입력받습니다. 획은 시작한 칸의 글자에 귀속됩니다 |
| 완료 표시 | 표시 | 칸에서 수집하는 자모를 모두 쓰면 칸의 배경색이 바뀝니다. 수집할 자모가 없는 칸(빈칸, 문장 부호, 자모가 모두 고정된 칸)은 그 뒤의 칸에 첫 획이 들어오면 배경색이 바뀝니다 |
| 쓰는 칸 표시 | 표시 | 팝오버가 열린 칸에 테두리를 표시합니다 |
| 칸 글자 | 표시와 버튼 | 칸의 오른쪽 아래에 글자를 표시합니다. 획이 있는 칸에서는 버튼이 되어, 누르면 그 칸의 팝오버를 다시 엽니다 |
| 고정 자모 | 표시 | 이미 수집한 자모를 회색 가이드로 칸에 표시합니다 |
| 자리 안내 상자 | 표시 | 쓰지 않은 자모의 자리를 점선으로 표시합니다 |
| 원본 칸 강조 | 표시 | PG-05에서 지정한 칸을 강조하고 그 위치까지 스크롤합니다 |

### 칸 팝오버

쓰고 있는 칸의 오른쪽에 붙어서 열립니다. 마지막 열의 칸에서는 왼쪽에 열립니다. 칸의 자모를 모두 수집하면 닫혀서 다음 칸을 가리지 않습니다.

| 요소 | 종류 | 동작 | 비활성 조건 |
|------|------|------|-------------|
| 자모 탭 | 선택 버튼 목록 | 이 칸에서 수집하는 자모를 쓰는 순서로 보여 줍니다. 지금 수집하는 자모를 강조하고, 끝난 자모에 완료 표시를 합니다. 탭을 누르면 그 자모로 수집을 옮깁니다 | 앞 자모에 획이 없을 때 |
| 남은 획수 | 표시 | 지금 수집하는 자모의 역할과 이름, 평소 획수까지 남은 획수를 보여 줍니다 | |
| 자모 완료 | 버튼 | 가장 최근 획에서 지금 자모의 수집을 미리 끝냅니다. 라벨은 「자모 완료」입니다 | 지금 자모에 획이 없을 때 |
| 닫기 | 아이콘 버튼 | 다시 연 팝오버를 닫습니다 | 칸 글자로 다시 열었을 때만 표시 |
| 나누기 경고 | 알림 | 나누기의 기준 획을 삭제하면 다시 확인하라고 알립니다 | 경고가 없으면 숨김 |

### 이동 영역

| 요소 | 종류 | 동작 | 표시 조건 |
|------|------|------|-----------|
| 이전 문장 | 아이콘 버튼 | 앞 문장을 엽니다 | 첫 문장에서는 비활성 |
| 다음 문장 | 버튼 | 다음 문장을 엽니다 | 마지막 문장이 아닐 때 |
| 폰트 만들기 | 버튼 | 폰트 생성을 시작합니다 | 마지막 문장일 때 |
| 지금 폰트 만들기 | 링크 버튼 | 폰트 생성을 시작합니다 | 마지막 문장이 아닐 때 |
| 기존 폰트 미리보기 · 편집 | 버튼 | 글리프에서 온 경우 PG-05를, 아니면 PG-04를 엽니다 | 생성된 폰트가 있을 때 |

## 대화상자

| 이름 | 표시 시점 | 내용 | 선택 |
|------|-----------|------|------|
| 수집하지 않은 글자 | 필수 항목이 비어 있는 상태에서 생성을 시작할 때 | 기본 글자, 문맥형, 기호의 빈 개수와 글자 목록 | 계속 작성하기: 닫습니다. 그래도 생성하기: 생성을 계속합니다 |
| 기존 글리프 보정 | 필기를 변경했고 보정한 글리프가 있을 때 | 보정한 글리프의 개수 | 보정 유지하고 재합성. 기존 보정 삭제 후 재합성. 취소 |

## 자동 저장

- 시스템이 획을 바꾼 뒤 250 ms가 지나면 현재 문장을 저장합니다.
- 시스템이 문장을 이동할 때 현재 문장의 번호를 저장합니다.

## 상태

| 상태 | 표시 |
|------|------|
| 획이 없음 | 칸 크기 조정 가능. 칸 팝오버 없음 |
| 획이 있음 | 칸 크기 고정. 마지막으로 쓴 칸에 수집할 자모가 남아 있으면 칸 팝오버 표시 |
| 해당 문장을 이전에 썼음 | 저장된 획, 자모 나누기, 가이드를 복원 |
