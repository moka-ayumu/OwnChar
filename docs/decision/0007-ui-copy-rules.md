# 0007 화면 문구 규칙

## Context

- 부가 설명이 많은 화면은 과해 보이고 AI가 만든 페이지처럼 느껴진다.
- 친근함을 연기하는 말투는 핵심을 흐린다.

## Decision

### 설명 문장

- 설명 없이 이해되는 컨트롤에는 문장을 두지 않는다. 부제, 안내 문단, "~해 보세요" 류의 권유를 쓰지 않는다.
- 설명이 필요하면 툴팁(`Hint`, `src/components/hint.tsx`)에 둔다.
- 툴팁은 설명하는 영역 전체를 감싼다. 제목만 감싸지 않는다. 슬라이더를 조절하는 동안에도 떠 있어야 한다.
- 제목은 명사구로 쓴다. 지시문으로 쓰지 않는다.
- 제목과 같은 말인 보조 문장을 쓰지 않는다. 보조 문장은 제목으로 설명되지 않는 정보가 있을 때만 쓴다.

### 어조

- 짧고 담백한 합쇼체나 명사형으로 쓴다. 사실을 말하고 끝낸다.
- 해요체를 쓰지 않는다. 친근함, 격려, 권유를 더하지 않는다.
- 확인창은 "~하시겠습니까?", 진행 중 메시지는 "~하는 중", 완료와 단계 설명은 "~합니다"로 쓴다.
- 예: "폰트 생성이 완료되었습니다.", "설정이 변경되어 재생성이 필요합니다."
- 고정 용어를 바꾸지 않는다: 수집, 문맥형, 고정 자모, 보정값, 변경 적용.

### 점검 순서

1. 이 문장이 없어도 컨트롤을 이해할 수 있는가. 그렇다면 쓰지 않는다.
2. 그렇지 않다면 툴팁에 둔다. 영역 전체를 감싼다.
3. 남는 문장은 합쇼체나 명사형으로 줄인다.
4. 제목과 같은 말인지 확인한다.

## Consequences

- 툴팁은 마우스를 올리거나 탭해야 보인다. 컨트롤 이름이 기능을 말하도록 쓴다.
- 읽는 것이 목적인 화면(도움말 본문)은 설명 문장을 둘 수 있다. 어조 규칙은 같이 적용한다.
