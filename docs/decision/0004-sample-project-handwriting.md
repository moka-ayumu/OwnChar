# 0004 샘플 프로젝트의 필기를 프로그램으로 만든다

## Context

- 샘플 프로젝트는 두 곳에서 쓴다.
  - 제품용: `src/features/samples/example.json`. 홈의 **예시 손글씨** 버튼이 읽는다. Git에 있다.
- 샘플 프로젝트는 수집 문장의 칸에 맞아야 한다. 문장이 바뀌면 샘플도 바뀐다.
- 사람이 문장을 쓰면 시간이 든다. 문장이 바뀔 때마다 같은 일이 생긴다.

## Decision

프로그램이 획을 만든다. 저장 형식은 앱의 코드가 만든다.

### 도구

- 생성기는 `tools/sample/`에 있다. 실행 방법은 `tools/README.md`에 있다.
- `handwriting.mjs`는 규칙이다: 자모의 뼈대, 음절의 배치, 간격, 스타일 값(`STYLES`).
- `generate.mjs`는 규칙으로 획의 좌표를 계산하고 프로젝트를 저장한다.
- 샘플을 바꾸려면 `handwriting.mjs`의 규칙이나 값을 바꾸고 `generate.mjs`를 다시 실행한다. 결과 파일을 직접 고치지 않는다.

### 파일과 저장 경로

- 생성기는 획(`RawStroke`)만 만든다.
- 생성기는 앱의 함수를 호출한다: `assignStrokes`, `captureRecords`, `saveSentenceCapture`. 그래서 저장 형식은 항상 현재 코드와 같다.
- 제품용 파일은 문장별로 세 가지만 저장한다: 격자(`cellSize`, `columns`), 획(`elements`), 자모의 끝(`boundaries`).
- 로더(`src/features/samples/sample-projects.ts`)는 같은 세 함수로 프로젝트를 다시 만든다.
- 제품용 파일은 약 0.7MB다. 전체 형식은 약 6.7MB다.

### 생성 순서

1. 자모의 뼈대를 단위 상자 안의 꺾은선으로 정한다.
2. 음절의 배치를 정한다. 배치는 초성, 중성, 종성의 자리다.
3. 뼈대를 칸의 픽셀 좌표로 옮긴다.
4. 자모 사이의 간격을 목표값에 맞춘다.
5. 음절의 잉크 중심을 칸의 가운데 줄에 맞춘다.
6. 획마다 작은 회전, 크기 변화, 위치 변화를 준다.
7. 자모 사이의 최소 거리를 잰다. 최소 거리가 한도보다 작으면 6번을 다시 한다.

난수 시드는 고정이다. 같은 입력은 같은 파일을 만든다.

### 배치 규칙

배치는 10가지다. 모음의 종류는 5가지다: 세로 모음, 가로 모음 `ㅗㅛ`, 가로 모음 `ㅜㅠ`, 가로 모음 `ㅡ`, 복합 모음. 각각 받침이 있는 형태와 없는 형태가 있다.

- 초성 `ㄱ`, `ㅋ`은 두 모양이 있다. 세로 모음 옆은 끝이 왼쪽으로 휜다. 가로 모음 위는 곧게 내려온다.
- 복합 모음(과, 관, 권)의 초성은 가로 모음 위의 모양을 쓴다.
- 세로 모음 옆의 초성은 모음의 가운데 높이에 둔다.
- 받침이 있는 음절은 받침이 없는 음절보다 길다(1.3배).
- 가로 모음과 복합 모음 음절은 초성의 자리를 위로 10% 늘린다. 획이 많은 `ㅊ`, `ㅎ`이 눌리지 않는다.
- 세로 모음 옆의 초성은 자리를 왼쪽으로 8% 늘린다.
- 세로 모음과 복합 모음 음절의 받침은 음절 폭의 60%를 쓴다.
- 쌍자음은 자리의 높이를 모두 쓴다.
- 자음마다 폭과 높이의 비율에 범위가 있다. 자리가 범위를 벗어나면 자음의 상자를 줄인다.

### 간격

간격은 펜의 중심선 사이의 거리다. 펜 굵기는 약 4.25px이다.

| 자모의 관계 | 목표 간격 |
|---|---:|
| 받침 없는 가로 모음 음절의 초성과 중성 | 16px |
| 세로 모음 옆의 초성과 중성 | 13px |
| 받침 없는 복합 모음 음절의 초성과 중성 | 13px |
| 받침과 위의 자모 | 13px |
| 받침 있는 가로 모음과 복합 모음 음절의 초성과 중성 | 10px |

- 간격이 목표보다 넓으면 자모를 당긴다. 간격이 목표보다 좁으면 자모를 민다.
- 최소 거리의 한도는 6.4px이다. 현재 파일의 최소 거리는 8.6px이다.
- 배치의 비율로 간격을 정하지 않는다. 음절을 길게 하면 간격도 같이 늘어나기 때문이다.

### 획의 모양

- 획은 곧다. 획마다 느린 굴곡을 넣지 않는다.
- 글자는 곧게 선다. 기울기는 거의 0이다.
- 모서리는 둥글다. 모서리마다 반지름이 다르다(기준의 40~100%).
- 납작한 자리(가로 모음 위, 받침)는 반지름을 60%로 줄인다.
- 모서리의 곡선은 획 길이의 30%를 넘지 않는다.
- `ㅇ`은 원이다. 가로와 세로의 차이는 4% 이내다. `ㅎ`의 원도 같다.
- 원은 조금 찌그러져 있다(1~2%). 원마다 모양이 다르다. 획의 끝은 시작점을 조금 지나 안쪽에서 끝난다.
- `ㅎ`, `ㅊ`의 윗부분은 수직의 짧은 획이다. 이 획은 아래의 가로획에 닿는다.
- `ㅈ`, `ㅊ`의 두 대각선은 가로획의 가운데에서 양쪽으로 내려온다.
- 펜 굵기 설정은 3이다(`strokeWidth` 0.5).

### 획 수와 자모의 끝

일부 자음은 보통보다 적은 획으로 쓴다. 두 획이 만나는 모서리는 한 획으로 이어 써야 둥글다.

| 자모 | 보통 획 수 | 샘플의 획 수 |
|---|---:|---:|
| ㄷ | 2 | 1 |
| ㅌ | 3 | 2 |
| ㄹ | 3 | 1 |
| ㅁ | 3 | 1 |
| ㅂ | 4 | 2 |
| ㅅ | 2 | 1 |
| ㅈ | 3 | 2 |
| ㅊ | 4 | 3 |

- 획 수가 보통과 다른 칸은 자모의 끝(`boundaries`)을 지정한다. 사용자가 칸의 팝오버에서 자모를 나누는 기능과 같다.
- 지정이 없으면 `assignStrokes`가 보통 획 수로 획을 나눈다. 그러면 초성이 중성의 획을 가져간다.
- 자모의 끝을 지정한 칸도 학습 표본이다(`completedHangulCells`).
- 현재 파일은 139칸 중 86칸에 자모의 끝이 있다.

### 손떨림 보정의 한도

- 손떨림 보정은 작은 닫힌 획을 원으로 만든다. 모서리의 반지름이 약 2.5px보다 크면 모서리가 사라진다.
- 한 획으로 쓰는 `ㅁ`은 모서리의 반지름을 그 한도 안에 둔다. 한도를 넘으면 `ㅁ`이 `ㅇ`으로 보인다.

### 줄

- 모든 음절의 잉크 중심은 칸의 가운데 줄에 있다. 흔들림은 0.8px이다.
- 음절마다 위치를 크게 흔들지 않는다. 글자가 한 줄로 이어지지 않기 때문이다.

### 영문, 숫자와 기호

- 대문자 높이는 46px이다. 기준선은 칸의 위에서 98px이다.
- 획 수는 제한이 없다. 칸에 슬롯이 하나다.

### 확인 방법

샘플을 다시 만들 때 다음을 확인한다.

1. 빠진 필수 문맥형이 없다(`missingPrompts`).
2. 139칸이 모두 학습 표본이다(`completedHangulCells`).
3. 최소 거리가 한도 이상이다.
4. 쓴 글씨의 시트를 눈으로 본다. 초성은 파랑, 중성은 자주, 종성은 초록이다.
5. 합성한 글리프의 시트를 본다. 빈 글리프가 없어야 한다.
6. 홈의 **예시 손글씨** 버튼으로 불러온다. 수집률은 229 / 229다.

눈으로 볼 항목은 다음과 같다.

- 획이 끊어진 곳이 없다. `ㅗ`의 짧은 획은 가로획에 닿는다.
- 한 자모의 획이 서로 뭉치지 않는다. 받침 `ㄹ`, `ㅌ`을 본다.
- 초성이 중성보다 지나치게 작지 않다. `ㅎ`, `ㅊ`, `ㅇ`을 본다.
- 받침이 위의 자모보다 지나치게 크지 않다.
- `ㅁ`이 `ㅇ`으로 보이지 않는다.
- 글자가 한 줄에 있다.

## Consequences

- 문장이 바뀌면 생성기를 다시 실행한다. 사람이 다시 쓰지 않는다.
- 저장 형식이 바뀌어도 제품용 파일은 그대로 쓴다. 로더가 다시 수집한다.
- 버튼을 누르면 로더가 획 735개를 다시 수집한다. 쓰기 화면이 열릴 때 0.2~0.3초의 멈춤이 두 번 있다.
- 샘플은 사람이 쓴 글씨가 아니다. 화면과 문서는 "예시 손글씨"라고 한다(`PRODUCT.md`).
- 개발용 샘플은 스타일 `tidy`로 만든다. 획에 굴곡이 있고 글자가 오른쪽으로 기운다. 획 수는 보통과 같다.
- 태블릿에서 로더가 걸리는 시간은 측정하지 않았다.

## Alternatives

- 사람이 문장을 쓴다. 문장이 바뀔 때마다 다시 써야 한다.
- 전체 형식(`{ meta, sessions, drawings }`)을 제품에 넣는다. 파일이 약 10배 크다. 저장 형식이 바뀌면 파일을 못 쓴다.
- 모든 자음을 보통 획 수로 쓴다. 두 획이 만나는 모서리가 각진다. 샘플이 자모의 끝을 지정하는 기능도 쓰지 않는다.
- 자음을 바깥으로 부풀리고 모음을 함께 휘게 한다. 획이 흔들려 보인다.
- 글자를 납작하게 누른다. 받침의 획이 뭉친다.
- `ㅇ`을 자리의 비율에 맞춘다. 받침 `ㅇ`이 타원이 된다. 손글씨의 `ㅇ`은 원에 가깝다.
